About this website

This website was designed and built by Reyan Ahmed Ayele, a graduate of the school's Class of 2017 E.C., as a volunteer project for Blessed Gebremichael. Reyan also keeps it up to date.

እንዴት እንደተሠራHow it was built

Made for the school, by one of its graduates

  • Plain HTML and CSS, with a little JavaScript for the phone menu. No website builder or template.
  • The first draft was made with the help of an AI assistant. Facts are checked with the school before they are published.
  • Hosted on GitHub Pages, where every change to the site is recorded.
  • Built to work on phones, in light and dark mode, and to print the School Profile.
